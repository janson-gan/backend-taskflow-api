# TaskFlow API

A production-grade task management REST API built with modern Node.js technologies.

## 🎯 Project Overview

TaskFlow is a scalable backend service for managing teams, tasks, and collaborative workflows. This project demonstrates professional software engineering practices including:

- ✅ Type-safe TypeScript development
- ✅ Comprehensive unit and integration testing
- ✅ RESTful API design principles
- ✅ Database design with PostgreSQL & Prisma ORM
- ✅ Authentication & authorization
- ✅ Production-ready error handling
- ✅ Clean code architecture
- ✅ Professional Git workflow

## 🛠 Tech Stack

### Backend

- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Express.js
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Validation:** Zod
- **Testing:** Vitest + Supertest

### Developer Tools

- **Package Manager:** npm
- **Task Runner:** npm scripts
- **Code Quality:** TypeScript strict mode
- **Git Workflow:** GitHub

## 📋 Prerequisites

- Node.js 18+
- npm 9+
- PostgreSQL 14+
- Git
